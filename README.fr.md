## Règles (30 secondes)

1. **Un chat par ligne**
2. **Un chat par colonne**
3. **Un chat par région colorée**
4. **Les chats ne se touchent pas** (diagonale comprise)

## Démarrage rapide

1. Ouvrez **[Jouer sur Guessingame](https://guessingame.org/meowdoku?utm_source=github&utm_medium=readme&utm_campaign=open-meowdoku&utm_content=fr)**  
2. Choisissez **Daily** ou **Levels**  
3. Touchez une case pour placer un chat ; marquez les cases dangereuses  
4. Respectez toutes les contraintes — progression stockée localement  

Pas de compte. Pas de téléchargement.
