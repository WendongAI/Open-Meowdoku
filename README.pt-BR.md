## Regras (30 segundos)

1. **Um gato por linha**
2. **Um gato por coluna**
3. **Um gato por região colorida**
4. **Gatos não se tocam** (incluindo diagonal)

## Começar

1. Abra **[Jogar no Guessingame](https://guessingame.org/meowdoku?utm_source=github&utm_medium=readme&utm_campaign=open-meowdoku&utm_content=pt-BR)**  
2. Escolha **Daily** ou **Levels**  
3. Toque para colocar o gato; use marcações para eliminar células inválidas  
4. Complete todas as regras — o progresso fica no armazenamento local do navegador  

Sem conta Guessingame. Sem download.
