## Kurallar (30 saniye)

1. **Her satırda bir kedi**
2. **Her sütunda bir kedi**
3. **Her renkli bölgede bir kedi**
4. **Kediler birbirine değmez** (çapraz dahil)

## Başlangıç

1. **[Guessingame’de oyna](https://guessingame.org/meowdoku?utm_source=github&utm_medium=readme&utm_campaign=open-meowdoku&utm_content=tr)** bağlantısını aç  
2. **Daily** veya **Levels** seç  
3. Hücreye dokunarak kedi koy; tehlikeli hücreleri işaretle  
4. Tüm kuralları sağla — ilerleme tarayıcı yerel depolamasında  

Hesap yok. İndirme yok.
