## 規則（30 秒）

1. **每行一隻貓**
2. **每列一隻貓**
3. **每個彩色區域一隻貓**
4. **貓不能互相接觸**（含對角線）

## 快速開始

1. 打開 **[Guessingame 遊玩頁](https://guessingame.org/meowdoku?utm_source=github&utm_medium=readme&utm_campaign=open-meowdoku&utm_content=zh-TW)**  
2. 選 **Daily** 或 **Levels**  
3. 點格子放貓，用標記排除危險格  
4. 滿足全部條件即過關（進度存在瀏覽器本機）  

無需帳號、無需下載。
