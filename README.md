## Rules (30 seconds)

1. **One cat per row**
2. **One cat per column**
3. **One cat per colored region**
4. **Cats cannot touch** (including diagonally)

That’s the whole game. Early levels take a minute; larger boards reward careful marking.

## Quick start (players)

1. Open **[Play on Guessingame](https://guessingame.org/meowdoku?utm_source=github&utm_medium=readme&utm_campaign=open-meowdoku&utm_content=en)**
2. Pick **Daily** or **Levels**
3. Tap a cell to place a cat; use mark mode to eliminate unsafe cells
4. Clear every constraint to win — progress stays in local browser storage

No Guessingame account. No download.
