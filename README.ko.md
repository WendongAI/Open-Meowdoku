## 이 저장소의 역할

GitHub에서 고양이 스도쿠 / Meowdoku류를 찾는 사람을 위한 **오픈 진입점**. 규칙·공략을 정리하고 실제 플레이는 Guessingame으로 안내합니다.

## 규칙 (30초)

1. **행마다 고양이 1마리**
2. **열마다 고양이 1마리**
3. **색 영역마다 고양이 1마리**
4. **고양이는 서로 닿지 않음** (대각선 포함)

## 시작하기

1. **[Guessingame에서 플레이](https://guessingame.org/meowdoku?utm_source=github&utm_medium=readme&utm_campaign=open-meowdoku&utm_content=ko)** 열기  
2. **Daily** 또는 **Levels** 선택  
3. 칸을 눌러 고양이를 두고, 위험 칸은 마크로 제거  
4. 모든 조건을 만족하면 클리어 (진행도는 브라우저 로컬 저장)

계정·다운로드 불필요.
