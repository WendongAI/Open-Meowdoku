## Правила (30 секунд)

1. **Один кот в строке**
2. **Один кот в столбце**
3. **Один кот в цветной области**
4. **Коты не касаются** (включая диагональ)

## Быстрый старт

1. Откройте **[Играть на Guessingame](https://guessingame.org/meowdoku?utm_source=github&utm_medium=readme&utm_campaign=open-meowdoku&utm_content=ru)**  
2. Выберите **Daily** или **Levels**  
3. Нажмите клетку, чтобы поставить кота; отметьте опасные клетки  
4. Выполните все условия — прогресс хранится локально в браузере  

Без аккаунта. Без скачивания.
