## Regeln (30 Sekunden)

1. **Eine Katze pro Zeile**
2. **Eine Katze pro Spalte**
3. **Eine Katze pro Farbregion**
4. **Keine Berührung** (auch diagonal)

## Schnellstart

1. **[Auf Guessingame spielen](https://guessingame.org/meowdoku?utm_source=github&utm_medium=readme&utm_campaign=open-meowdoku&utm_content=de)** öffnen  
2. **Daily** oder **Levels** wählen  
3. Zelle tippen, um eine Katze zu setzen; unsichere Felder markieren  
4. Alle Bedingungen erfüllen — Fortschritt lokal im Browser  

Kein Konto. Kein Download.
