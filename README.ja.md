## ルール（30秒）

1. **各行に猫は1匹**
2. **各列に猫は1匹**
3. **各色領域に猫は1匹**
4. **猫どうしは隣接しない**（斜めも不可）

## はじめ方

1. **[Guessingame で遊ぶ](https://guessingame.org/meowdoku?utm_source=github&utm_medium=readme&utm_campaign=open-meowdoku&utm_content=ja)** を開く  
2. **Daily** か **Levels** を選ぶ  
3. マスをタップして猫を置き、危険マスはマークで消す  
4. すべての制約を満たせばクリア（進捗はブラウザのローカル保存）

アカウント不要・ダウンロード不要。
