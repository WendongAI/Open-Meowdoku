# How to play Open-Meowdoku

**Play free now → [guessingame.org/meowdoku](https://guessingame.org/meowdoku?utm_source=github&utm_medium=docs&utm_campaign=how-to-play)**

Open-Meowdoku is a browser cat-placement logic puzzle. You do not need numbers like classic Sudoku — you place cats under four rules.

## Before you start

1. Open the live game: [https://guessingame.org/meowdoku](https://guessingame.org/meowdoku?utm_source=github&utm_medium=docs&utm_campaign=how-to-play)
2. Choose **Daily** (one puzzle per calendar day) or **Levels** (80 handcrafted boards)
3. No account and no download — it runs in a modern browser

## The four rules

| Rule | Meaning |
|------|---------|
| One per row | Every row gets exactly one cat when solved |
| One per column | Every column gets exactly one cat |
| One per region | Each colored region gets exactly one cat |
| No touching | Cats cannot sit in neighboring cells, including diagonals |

If any rule breaks, the placement is illegal.

## Step-by-step first solve

1. Scan **small regions** first — fewer cells means fewer legal spots.
2. Tap a safe cell to place a cat.
3. Mentally (or with mark mode) block that row, column, and all eight neighbors.
4. Look for a row or column that now has only one safe open cell — place there.
5. Repeat until every region has its cat.
6. Use a **hint** only after you have marked eliminations; undo beats full reset.

## Modes on Guessingame

- **Daily** — deterministic puzzle for the UTC calendar day so friends can compare times later
- **Levels** — curated difficulty ladder
- **Ranking** — local completion times on this device (browser storage)
