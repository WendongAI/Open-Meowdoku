# Open-Meowdoku FAQ

**Play free → [https://guessingame.org/meowdoku](https://guessingame.org/meowdoku?utm_source=github&utm_medium=docs&utm_campaign=faq)**

### What is Open-Meowdoku?

Open-Meowdoku is the open docs + play hub for a free browser cat-logic puzzle: one cat per row, column, and colored region, with no touching (including diagonals).

### Where can I play it?

Play in the browser at [guessingame.org/meowdoku](https://guessingame.org/meowdoku?utm_source=github&utm_medium=docs&utm_campaign=faq). No install.

### Is it free?

Yes. Guessingame does not put a paywall on Meowdoku. Progress uses local browser storage.

### Do I need an account?

No Guessingame account is required.

### Is this the same as the viral mobile Meowdoku app?

No. The popular mobile title is a separate commercial product (e.g. Oakever Games). Open-Meowdoku / Guessingame are **not affiliated** with that app. The browser game is adapted from the open-source MimoDoku project (MIT).

### Is the source of the rules open?

Yes. Lineage: [MkThingsHQ/mkgame-sudoku](https://github.com/MkThingsHQ/mkgame-sudoku) (MimoDoku), MIT. See [NOTICE](../NOTICE).

### Can I play offline?

Keep the Guessingame tab open after first load. There is no separate offline install package in this repo — the live product is the website.
